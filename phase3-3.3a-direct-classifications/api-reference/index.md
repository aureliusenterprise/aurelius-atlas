# API Reference

Generated API documentation for the Aurelius Atlas workspace, rendered from the docstrings in each project by [mkdocstrings](<https://mkdocstrings.github.io/>). The prose for *what a project is* lives in its `README.md`; the wiring for *how it is built and run* lives in its `AGENTS.md` (ADR 003). This tree is the reference for *what it exposes*: classes, functions, signatures, and examples.

Each page doubles as that component's **design documentation**: the technology-specific detail of how the component works — settings and knob names, storage layout, protocol mechanics, ports, commands. The [architecture](<https://aureliusenterprise.github.io/phase3-3.3a-direct-classifications/architecture/index.md>) trees state the technology-neutral properties the component must keep. A page's **Design** section carries this detail, with the ADR that owns each rule linked.

- [Apps](<https://aureliusenterprise.github.io/phase3-3.3a-direct-classifications/api-reference/apps/index.md>) — the services: the Atlas server and the template examples
- [Libs](<https://aureliusenterprise.github.io/phase3-3.3a-direct-classifications/api-reference/libs/index.md>) — the Python, Angular, and style libraries the apps consume
