# User Guide

Aurelius Atlas helps your organisation make data-driven decisions:

- **Discover, search, and understand your data** — find a data asset and its context in seconds, including who to ask about it.
- **Improve efficiency** — see who is accountable for each asset, which systems to connect to for access, and whether the data is fit for purpose.
- **Track data lineage** — follow the journey and transformations of your data across systems, and see what a change would affect.
- **Enhance data compliance** — classify sensitive information and keep an audit trail of what changed, in line with regulations such as GDPR.
- **Guide data quality efforts** — use classifications and impact analysis to prioritise where governance controls pay off.

The Aurelius Atlas open-source release serves the Apache Atlas REST API (`/api/atlas/v2/...`) and the Apache Atlas dashboard, so those capabilities arrive with the behaviour Atlas users already know. Until the conversion is complete, the [Apache Atlas documentation](<https://atlas.apache.org/2.4.0/index.html>) describes the behaviour this system reproduces; every intended difference is listed in [Deviations from Apache Atlas](<https://aureliusenterprise.github.io/feat-chart-foundation/architecture/conversion/deviations/index.md>).

If you are setting up your machine for the first time, see the [Development Environment](<https://aureliusenterprise.github.io/feat-chart-foundation/contributor-guide/development-environment/index.md>) guide instead.
