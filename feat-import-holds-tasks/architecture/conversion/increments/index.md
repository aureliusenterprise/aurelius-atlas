# Increments

An increment's semantics specification lives in the project it touches: it is written before the code ([ADR 051](<https://aureliusenterprise.github.io/feat-import-holds-tasks/architecture/adr/051-the-conversion-proceeds-in-specified-increments/index.md>)) as `<project>/specs/N-M-slug/spec.md`, with its `DD-NNN` records in `design.md` beside it. An increment that spans two projects gets one part per project, sharing the rule table; the increment-to-project map is [Spec Map](<https://aureliusenterprise.github.io/feat-import-holds-tasks/architecture/conversion/spec-map/index.md>).

The pages below are the specifications written before the move: kept here as history until their series moves. Copy [the template](<https://aureliusenterprise.github.io/feat-import-holds-tasks/architecture/conversion/increments/template/index.md>) to start a new one, add its project's `specs` directory to the `specs` roots in the root `pyproject.toml`, and keep its status in step with the [roadmap](<https://aureliusenterprise.github.io/feat-import-holds-tasks/architecture/conversion/#roadmap>).
