# Patches to the vendored dashboards

`dashboardv2/` and `dashboardv3/` are the Apache Atlas `release-2.4.0` source (commit 4787b75 of
`github.com/apache/atlas`). These are the only changes made to them (DSH-05,
[DD-017](../../docs/architecture/conversion/design-log.md#dd-017-the-dashboards-are-vendored-unchanged-and-built-with-dart-sass-on-node-24)).
Each patch is one commit; `git log -- apps/aurelius-atlas-dashboard/dashboardv2 apps/aurelius-atlas-dashboard/dashboardv3`
lists them.

| #   | Files (both dashboards)                             | Change                                                                                   | Reason                                                                                                           | Increment |
| --- | --------------------------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------- |
| 01  | `gruntfile.js`, `package.json`, `package-lock.json` | `node-sass` 9.0.0 replaced by `sass` (dart-sass) 1.105.2; lockfile regenerated by npm 11 | `node-sass` is native and builds only on Node 16 to 20, which is past its end of life; dart-sass runs on Node 24 | 0.6       |

To check that nothing else changed, compare with the tag:

```bash
git clone --depth 1 --branch release-2.4.0 https://github.com/apache/atlas.git /tmp/atlas-2.4.0
diff -r /tmp/atlas-2.4.0/dashboardv3 apps/aurelius-atlas-dashboard/dashboardv3   # only the files above differ
```
