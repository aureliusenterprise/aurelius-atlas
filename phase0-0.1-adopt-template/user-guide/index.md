# User Guide

Aurelius Atlas serves the Apache Atlas REST API (`/api/atlas/v2/...`) and the Apache Atlas dashboard. Until the conversion is complete, the [Apache Atlas documentation](<https://atlas.apache.org/2.4.0/index.html>) describes the behaviour this system reproduces; every intended difference is listed in [Deviations from Apache Atlas](<https://aureliusenterprise.github.io/phase0-0.1-adopt-template/architecture/conversion/deviations/index.md>).

If you are setting up your machine for the first time, see the [Development Environment](<https://aureliusenterprise.github.io/phase0-0.1-adopt-template/contributor-guide/development-environment/index.md>) guide instead.
