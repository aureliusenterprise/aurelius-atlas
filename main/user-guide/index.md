# User Guide

This guide describes how to design and build data products on the platform: how events are produced to and consumed from the shared event backbone, how topics are organized, and how schemas keep producers and consumers compatible.

Start with the [Design Guide](<https://aureliusenterprise.github.io/main/user-guide/design-guide/index.md>), which covers:

- [Producers](<https://aureliusenterprise.github.io/main/user-guide/design-guide/producers/index.md>): how to publish events to the backbone.
- [Consumers](<https://aureliusenterprise.github.io/main/user-guide/design-guide/consumers/index.md>): how to subscribe to and integrate with shared streams.
- [Kafka Topics](<https://aureliusenterprise.github.io/main/user-guide/design-guide/kafka-topics/index.md>): how topics are named, partitioned, and retained.
- [Schemas](<https://aureliusenterprise.github.io/main/user-guide/design-guide/schemas/index.md>): how event schemas are defined, registered, and evolved.

If you are setting up your machine for the first time, see the [Development Environment](<https://aureliusenterprise.github.io/main/contributor-guide/development-environment/index.md>) guide instead.
