# aurelius-atlas-dsl

[![SonarQube Cloud](https://sonarcloud.io/images/project_badges/sonarcloud-light.svg)](https://sonarcloud.io/summary/new_code?id=aureliusenterprise_aurelius-atlas-dsl)

The Atlas DSL for Aurelius Atlas, without I/O
([DD-002](../../../docs/architecture/conversion/design-log.md#dd-002-atlas-code-lives-in-aurelius-atlas-projects-split-by-layer)).
Since increment [4.3](../../../docs/architecture/conversion/increments/4-3-dsl-parser.md): a query parsed by
Atlas's own grammar, with Atlas's syntax errors, into a typed syntax tree; and the clauses, limit and offset
it asks for. The parser is generated by ANTLR from `grammar/`, Atlas's `AtlasDSLLexer.g4` and
`AtlasDSLParser.g4` unchanged (DD-240).

```python
from aurelius_atlas_dsl.atlas_dsl import QueryMetadata, parse

query = parse("hive_table where name = 'sales' select name limit 10")  # raises AtlasError INVALID_DSL_QUERY
query.sources[0].where.expr.comp_e.operator  # Operator.EQ
QueryMetadata.of(query).resolved_limit  # 10
```
