# aurelius-atlas-model

Atlas data shapes without I/O (DD-002, DD-020). This file covers wiring specific to this lib;
workspace-wide rules — including the scaffold recipe for Python libs — live in the root `AGENTS.md` and
`libs/python/AGENTS.md`.

## Layout

- `aurelius_atlas_model/typedef.py` — the typedef models (`org.apache.atlas.model.typedef`), their enums
  and the built-in type names
- `aurelius_atlas_model/patches.py` — `AtlasPatch` and `PatchStatus` (`org.apache.atlas.model.patches`)
- `aurelius_atlas_model/base.py` — `AtlasModel` and the JSON types every model shares (timestamps, Java
  scalars, sets)
- `aurelius_atlas_model/codec.py` — Atlas's JSON: floats read as `Decimal`, decimals and dates written as
  Jackson writes them (VAL-01, DD-039)
- `aurelius_atlas_model/instance/` — the entity models (`org.apache.atlas.model.instance`), one module per
  Java class, nested classes and enums included (DD-037); `__init__.py` re-exports them
- `tests/` — TDM-01 to TDM-20; `tests/instance/` — ENT-01 to ENT-18, one `test__instance_<module>.py` per
  module (the four enums share `test__instance_statuses.py`); `tests/fixtures/` holds Atlas's
  `0010-base_model.json`, `0011-glossary_model.json` and six hive hook messages, unchanged

## Conventions

- Python attributes are snake_case; the JSON names are the Java getter names, generated by `to_camel`
  (TDM-01). A Java name `to_camel` does not produce needs an explicit alias.
- Write response bodies with `to_json()`: by alias, nulls left out, empty collections kept (TDM-02). Its
  untyped values keep `Decimal` and `datetime`, so encode it with `codec.dumps`, never `json.dumps`.
- A Java setter that normalises its input becomes an `_`-prefixed validator on the field, so it runs
  on reading, construction and assignment (`validate_assignment`), as the Java setter does.
- A new instance class gets its own module under `instance/`, named after the Java class in snake_case
  without `Atlas`, and an export in `instance/__init__.py`.
- No I/O, no settings, no registry lookups: resolving type names is `aurelius-atlas-typesystem` (1.2, 1.3).
