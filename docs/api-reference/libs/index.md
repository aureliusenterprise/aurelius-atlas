# Libs

API reference for the workspace libraries, grouped by stack. Each library documents itself in its
`README.md`; this tree lists what it exposes.

- [Python](python/index.md) — the Atlas code: model, typesystem, core, store, tooling
- [Angular](angular/index.md) — the template frontend's data, UI, and observability libraries
- [Styles](styles/index.md) — design tokens shared by the Angular apps
