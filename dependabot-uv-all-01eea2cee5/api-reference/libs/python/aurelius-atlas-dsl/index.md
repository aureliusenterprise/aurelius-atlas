# aurelius-atlas-dsl

The Atlas DSL for Aurelius Atlas, without I/O ([DD-002](<https://aureliusenterprise.github.io/dependabot-uv-all-01eea2cee5/architecture/conversion/design-log/#dd-002-atlas-code-lives-in-aurelius-atlas-projects-split-by-layer>)). Since increment [4.3](<https://aureliusenterprise.github.io/dependabot-uv-all-01eea2cee5/architecture/conversion/increments/4-3-dsl-parser/index.md>): a query parsed by Atlas's own grammar, with Atlas's syntax errors, into a typed syntax tree; and the clauses, limit and offset it asks for. The parser is generated by ANTLR from Atlas's `AtlasDSLLexer.g4` and `AtlasDSLParser.g4`, unchanged ([DD-240](<https://aureliusenterprise.github.io/dependabot-uv-all-01eea2cee5/architecture/conversion/design-log/#dd-240-the-dsl-parser-is-generated-from-atlass-own-grammar>)).

```
from aurelius_atlas_dsl.atlas_dsl import QueryMetadata, parse

query = parse("hive_table where name = 'sales' select name limit 10")  # raises AtlasError INVALID_DSL_QUERY
query.sources[0].where.expr.comp_e.operator  # Operator.EQ
QueryMetadata.of(query).resolved_limit  # 10
```

## aurelius\_atlas\_dsl.dsl\_tree

The Atlas DSL's parse tree as typed, immutable nodes (DD-241).

One node per rule of `AtlasDSLParser.g4` that `DSLVisitor` reads, named after it; a rule that only chooses (`literal`, `atomE`, `compE`, `fromSrc`, `singleQrySrc`) is the union of its alternatives, and `querySrc`, `selectClause`, `limitClause` and `offsetClause` are folded into their parent. Every node keeps `text`, the rule's `getText()`: its tokens joined without the spaces and comments the lexer skipped (DSL-05).

## aurelius\_atlas\_dsl.tree\_builder

Turns ANTLR's parse tree of a query into the nodes of `dsl_tree` (DD-241, DSL-05).

Each function reads one context of `AtlasDSLParser`: the parts `DSLVisitor` reads through the generated accessors, here by their context class or token type, which pyright can follow. A context that `parse` accepted always has the parts its rule requires.

Functions:

- **`build_query`** –

  The `Query` of a parsed `query` context.

### build\_query

```
build_query(ctx: QueryContext) -> Query
```

The `Query` of a parsed `query` context.

Parameters:

- #### **`ctx`**

  (`QueryContext`) –

  The context `AtlasDSLParser.query` returned without a syntax error.

Returns:

- `Query` –

  Its syntax tree; the query's text ends in `<EOF>`, as `getText()` gives it.
